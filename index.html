☁️ Sincronização na Nuvem (Firebase)
Como funciona: O sistema usa o Google Firebase (gratuito) para salvar seus dados na nuvem.
Assim você acessa de qualquer computador, celular ou navegador e os dados ficam sempre sincronizados.
⚠️ Siga o guia abaixo para configurar — leva só 5 minutos.
⚪ Firebase não configurado
📖 Guia passo a passo — como criar o Firebase gratuito
1. Acesse console.firebase.google.com com sua conta Google.
2. Clique em "Criar um projeto" → dê o nome clinica-elos → desative o Google Analytics → clique em Criar.
3. No menu lateral, clique em "Firestore Database" → "Criar banco de dados".
4. Escolha "Iniciar no modo de teste" → selecione a região southamerica-east1 (São Paulo) → Ativar.
5. No menu lateral, clique em ⚙️ "Configurações do projeto".
6. Role até "Seus aplicativos" → clique no ícone </> (Web) → dê o nome elos-web → clique em Registrar app.
7. Vai aparecer um bloco de código com firebaseConfig. Copie os valores e cole nos campos abaixo.
8. Clique em "Salvar e Conectar" — pronto! 🎉
🔒 Segurança — Senha de Acesso
O sistema bloqueia automaticamente após 10 minutos de inatividade.
Altere a senha padrão elos2024 para uma senha pessoal.
🗄️ Backup Manual (sempre recomendado!)
Exporte um arquivo de backup com todos os seus dados. Guarde em lugar seguro como proteção extra.
